Engineering report1
01 · Problem

What this system had to solve

Product constraint

  • One funded account, $1,500 buying power
  • Options first, equity fallback
  • Max one open position, one contract
  • Watchlists as the only universe
  • No crypto, no shorts, no multi-leg

Engineering constraint

  • Broker access is Robinhood MCP, not a custom OMS
  • No OCO / bracket orders in the tool set
  • Cursor Automations are stateless discrete fires
  • Cloud agents can invent numbers unless gated
  • MCP exposes every tool once connected

The build is a gated decision pipeline plus two place authorities — not a continuously running trading server.

Engineering report2
02 · Design principles

Fail-closed, honest numbers, one kill switch

  1. Fail closed. Missing clock, account, quote, delta, spread, or buying power → place nothing.
  2. Do not invent market data. Greeks only from get_option_quotes. No Black–Scholes fallback.
  3. Spec is code. Locked rules live in config/rules.json and config/autonomous_permissions.json.
  4. Agents are modules, not fleets. A–E + I are functions in one pipeline. One Automation (H) may place.
  5. Two authorities, never mixed. This chat needs a specific-order confirm. H has standing permission only while the Automation is enabled.
  6. Mask secrets in git. Full account numbers only in RH tool args. Journal and reports use ••••2907.

08 · Pattern engine

Deterministic heuristics, strict majority

detect_patterns

  • Needs ≥30 OHLC bars
  • Local extrema, order = 3
  • H&S, inverse H&S, double/triple top & bottom, triangles
  • ~1.5% near-equality on peaks/troughs
  • Each hit carries bullish or bearish

dominant_bias

  • Count bullish vs bearish hits
  • Require strict majority
  • Tie or empty → null → no option structure
  • H cost control: daily first; 10m + 1h only on daily hits; stop at one bias

RH MCP has no 15minute interval. Closest bar is 10minute. Rules JSON still lists 15m as the intended TF; live scans used 10m.

Engineering report10
10 · Honesty gates

Greeks and spread refuse invention

extract_greeks

  • Copies delta, gamma, theta, vega, rho, IV only if present
  • Missing fields listed, never filled
  • delta_in_band uses abs(delta) 0.40–0.50
  • 0.396 (NU) and 0.522 (META) both fail — the band is closed

option_quote_liquid

  • mid = (bid+ask)/2
  • spread% = (ask−bid)/mid
  • Prefer ≤5%, accept ≤10%, reject >10%
  • Reject one-sided or mid ≤ 0
  • No $0.10 absolute override

Cheap names fail on percent width even when the dollar spread looks small. That is intentional.

Engineering report11
11 · Risk and exits

Math in-repo; broker has no OCO

options_risk_plan

  • Keyword-only premium_per_share
  • Cash = premium × 100 × 1
  • Locked pair: SL 20%, TP 40% → 1:2
  • Bands enforced: SL 20–50%, TP ≥ 30%
  • Raises if contracts ≠ 1

Stop-first until OCO exists

  • MCP cannot rest a true OCO
  • Two live exits can double-fill
  • After fill: broker STOP only
  • TP watched on a later RTH fire
  • Equity fallback: +25% / −20% of cost

SNOW Sep 4 327.5 put cleared spread and delta on Friday marks, then failed affordability: $1,975 cash vs $1,500 buying power.
