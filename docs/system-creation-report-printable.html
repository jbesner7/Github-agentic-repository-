1. Purpose and what was created

A multi-agent Robinhood automation for one account (Agentic). The design priority is options first, equity fallback, human-supervised place from this Cursor chat, and an optional unsupervised Cursor Automation (Agent H) that the owner can toggle at cursor.com/automations.

Built

  • Locked spec in config/rules.json
  • Printable Phase 0 plan + this report
  • Python pipeline agents A–E, I, F (dry review)
  • Chart + options playbooks
  • One live read-only signal cycle
  • One broker review (no place)
  • Agent H paste-ready Automation prompt
  • 13 unit tests passing

Not built / not live

  • No place_* from this chat
  • No Cursor Automation created or activated
  • No always-on Phase 4 loop process
  • No OCO / bracket at the broker (MCP has none)
  • No crypto trading (excluded)
  • No live-ready option ticket under current spread rule

3. Locked trading rules (current)

UniverseAll Robinhood watchlists (current + future), including Options Watchlist. No crypto (currency_pair, tokenized_stock). Deduplicate. Index underlyings/options allowed.
PriorityOptions first. Equity only if no option candidate clears gates.
PatternsH&S, inverse H&S, double/triple top & bottom, ascending / descending / symmetrical triangles. Timeframes: 15m, 1h, daily. Bias needs a strict majority; neutral → no options structure.
Options structureLong call or long put only. No shorts, no credit spreads, no multi-leg. DTE 0–7. ATM then one OTM. abs(delta) 0.40–0.50 from RH quotes only. Never invent Greeks.
LiquidityUnderlying ADV ≥ ~2,000,000. Option bid–ask prefer ≤ 5% of mid; reject > 10%. No $0.10 absolute override. Reject one-sided quotes.
Options exitsBand SL 20–50% / TP 30–100%+ of premium, aim 1:2. Owner-locked working pair −20% / +40%. After fill: broker STOP only (no OCO in this MCP). Monitor TP on later RTH runs.
Equity exitsTP +25% / SL −20% of trade cost. Same stop-first rule.
Session (Automation)Scan and buy only in US RTH: Mon–Fri 09:30–16:00 America/New_York, cash session open. market_hours=regular_hours on entries. Outside RTH: no scan, no buy.
PDTDo not throttle day-trade frequency. Owner accepts risk. Owner stated PDT “no longer exists” — not independently verified as law in this repo.
ConfirmsThis chat: every live order. Agent H: standing prompt is the confirm for that Automation only.

13. Honesty, PDT, and non-verification

  • Greeks: only values returned by get_option_quotes. No Black–Scholes fallback unless the owner later asks.
  • PDT: operational instruction is “do not throttle.” Owner claim that PDT no longer exists is not verified as securities law here.
  • Holiday calendar: Automation must not invent one. After the ET clock says RTH, if RH shows regular session closed, treat as outside RTH.
  • Historical signals/* files are snapshots. They still show old −7% / +20% and DRAFT playbook from the time they were written.
